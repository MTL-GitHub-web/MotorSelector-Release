# μDD Motor Selector（配布用）

μDD モータ（MTL MD series）選定プログラムの配布ページです。Windows 10 / 11（64 bit）用。

## はじめて使う方
1. 右の **[Releases](../../releases/latest)** を開き、`MotorSelectionProgram_Windows_v<版>.zip` をダウンロードします。
   （`MotorSelector_app_…` `MotorSelector_runtime_…` `manifest.json` は自動更新用です。ダウンロード不要）
2. zip を右クリック →「プロパティ」→ 下の **「許可する」** にチェック →「OK」。
3. zip を右クリック →「すべて展開」で、**自分のユーザーフォルダ**（例 `C:\Users\<名前>\MotorSelector`）に展開します。
   Program Files など管理者権限が必要な場所には置かないでください（自動更新できなくなります）。
4. 展開したフォルダの **`Setup.bat`** をダブルクリックします（初回だけ）。
   「デスクトップにも作りますか？」で「はい」を押すと、フォルダとデスクトップに起動用ショートカット「μDD Motor Selector」ができます。
   「Windows によって PC が保護されました」と出た場合は「詳細情報」→「実行」。
5. 次回からはショートカット「μDD Motor Selector」をダブルクリックして起動します。
   フォルダを移動したときは、もう一度 `Setup.bat` を実行してください。

> Ver.1.8.0 の `MotorSelectionProgram.exe` は、ウイルス対策ソフトに誤って検出・削除されることがありました。
> Ver.1.8.1 からは exe を使わず、同梱の Python をショートカットから起動する方式に変更しています。

## 2回目以降（自動更新）
起動時に新しい版があると「最新Verが公開されています。更新しますか？」と表示されます。
「はい」で自動的にダウンロード・入れ替え・再起動します。「あとで」を選ぶと今の版のまま使えます。
「改訂履歴」タブから「更新を確認」「前の版に戻す」もできます。

## 注意

- 不具合・要望はアプリの「改定依頼」タブから作成者へ連絡してください。
